# Spring Boot CRUD Application

A simple REST API application built using **Spring Boot** that demonstrates the fundamental CRUD (Create, Read, Update, Delete) operations. It allows users to manage employee records and perform database operations efficiently.

## 🚀 Features

- **Create:** Add new employee records.
- **Read:** Retrieve employee details by ID.
- **Update:** Modify existing employee information.
- **Delete:** Remove employee records.
- RESTful API development using Spring Boot.
- Database interaction using Spring Data JPA.
- Handling HTTP responses and status codes.

## 🛠️ Tech Stack

- Java
- Spring Boot
- Spring Data JPA
- Hibernate
- REST API
- Maven
- PostgresSQL
